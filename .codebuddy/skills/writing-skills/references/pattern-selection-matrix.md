# Skill 模式选择矩阵

本文件只在不确定某个 skill 到底该写成哪种结构时读取。

## 快速表

| 任务特征 | 推荐模式 | 主文件应该强调什么 |
|---|---|---|
| 需要审美、判断力、品味 | Mindset | 何时用、反模式、判断框架 |
| 场景分叉多、细节应该下沉 | Navigation | 路由、资源触发、何时不要加载 |
| 多阶段、多检查点、多门禁 | Process | 阶段协议、暂停条件、交付证据 |
| 文件格式、脚本、精细操作风险高 | Tool | 决策树、强约束、脚本边界 |

## 什么时候优先 Navigation

1. 一个 skill 同时支持多个子场景
2. 主文件已经开始堆长示例或模板
3. 细节规则只在特定阶段才需要

## 什么时候优先 Process

1. 任务需要分阶段推进
2. 阶段间存在明显暂停点或人工确认点
3. 输出不是一次性答案，而是阶段性交付

## 什么时候优先 Tool

1. 错一步代价高
2. 有明确脚本或命令边界
3. 需要强制质量门禁

## 常见选错

1. 把 Process 写成教程步骤
2. 把 Navigation 写成“大而全主文件”
3. 把 Tool 写成松散建议
4. 把 Mindset 写成鸡汤
