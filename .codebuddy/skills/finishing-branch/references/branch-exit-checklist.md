# 分支收尾清单

本文件只在真正进入收尾阶段后读取。按所选路径执行，不要把全部动作混成一轮。

## 通用收尾清单

所有路径都至少检查：

1. 关键验证已跑完并有证据
2. 未提交改动状态清楚
3. 调试日志、临时脚本、临时 mock 已清理
4. 文档、进度、风险说明已同步
5. 当前 owner 与最终收口人明确

## 路径 A：创建 PR / MR

额外检查：

1. 变更摘要可读，不只是罗列文件
2. 已跑验证与剩余风险可被 reviewer 快速看到
3. 若用过子代理或多 lane，实现了整体视角集成说明

## 路径 B：直接合并主干

额外检查：

1. 已明确不再需要额外审查
2. 合并策略、回滚点、主干基线都清楚
3. 危险操作已获确认

## 路径 C：保留分支

额外检查：

1. 说明为什么保留
2. 说明保留期限或下一次触发条件
3. 说明当前还差什么才能进入 A 或 B

## 路径 D：放弃分支

额外检查：

1. 说明为什么放弃
2. 说明是否需要保留对比点、commit 或文档证据
3. 删除前确认没有未保存成果

## Worktree 清理

如果使用过 worktree，再检查：

1. 目标分支与 worktree 的关系已说明白
2. `git worktree list` 的预期结果清楚
3. 强制删除前已经确认不会丢成果
