# 金融建模与格式标准

本文件只在交付物是金融模型、管理报表或对格式有明确要求的工作簿时读取。普通数据清洗或简单导出不需要加载本文件。

## 通用输出要求

1. 默认使用统一的专业字体，除非现有模板已有固定字体约定
2. 交付前必须没有公式错误：`#REF!`、`#DIV/0!`、`#VALUE!`、`#N/A`、`#NAME?`
3. 如果修改现有模板，优先复用原有样式、格式和布局，不要顺手“标准化”

## 金融模型颜色约定

除非现有模板另有规定：

1. 蓝色文字：硬编码输入值、用户会修改的假设
2. 黑色文字：公式和计算结果
3. 绿色文字：同工作簿内其他工作表引用
4. 红色文字：外部文件引用
5. 黄色背景：关键假设或需要人工关注的单元格

## 数字格式

1. 年份显示为文本样式，不加千分位
2. 货币列写清单位，如 `收入 ($mm)`
3. 零值显示为 `-`
4. 百分比默认 `0.0%`
5. 倍数默认 `0.0x`
6. 负数默认用括号而不是负号

## 硬编码值与来源

如果工作簿里存在硬编码假设值，必须记录来源，至少说明：

1. 来源系统或文档
2. 日期
3. 具体引用位置
4. 链接（如果有）

不要留下“只有结果，没有来源”的硬编码输入。
