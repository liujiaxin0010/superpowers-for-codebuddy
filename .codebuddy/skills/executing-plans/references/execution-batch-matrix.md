# 批次执行矩阵

本文件只在切批或暂停策略不够明确时读取。若当前批次边界、验证链路和回退方式都已清楚，不需要加载本文件。

## 快速切批表

| 情况 | 推荐动作 | 原因 |
|---|---|---|
| 共享接口、数据模型、公共配置变更 | 单独成批 | 先暴露共享回归面 |
| 高风险集成、迁移、删除、回滚准备 | 提前成批 | 尽早验证风险面 |
| 多个任务共享同一验证命令与同一模块 | 可合批 | 证据链路统一 |
| 出现人工确认点 | 立即停批 | 不能跨确认点继续推进 |
| 外部依赖接入、生产级动作 | 先做 dry-run / 准备批 | 避免误触真动作 |

## 每个批次最小字段

1. 目标
2. 允许修改范围
3. 验证命令
4. 完成定义
5. 回退方式
6. owner

缺任何一项，都不应该开批。

## 暂停而不是硬顶的情况

1. 验证失败但根因不明
2. 影响面超出合同边界
3. 发现共享契约改动计划未覆盖
4. 真实回滚、生产动作、外部依赖接入尚未获批

## 只做 dry-run 的情况

1. 计划里提到了回滚，但没有显式授权真实回滚
2. 变更涉及迁移、删除、生产数据或权限
3. 恢复命令和快照点还没记录

## 批次完成证据

至少包含：

1. 改了什么
2. 跑了什么验证
3. 验证结果
4. 剩余风险
5. 下一批或下一步
