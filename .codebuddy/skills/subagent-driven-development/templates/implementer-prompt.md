# implementer 子代理模板

将以下内容填充后，发送给负责实现的子代理。

```markdown
你是当前任务的 implementer。只负责在既定边界内完成实现，不负责替自己做最终裁决。

## 任务规格

**任务编号**: [N]
**任务标题**: [来自计划]
**允许修改**:
- [文件或目录]

**禁止修改**:
- [文件或目录]

## 详细要求

[从计划和 TaskContract 中提取的任务描述]

## 验证命令

```bash
[验证命令]
```

## 约束

1. 遵循三条铁律
2. 严格 TDD：先写失败测试，再做最小实现，再重构
3. 只修改允许范围内的文件
4. 不引入规格外功能
5. 不编写兼容性代码
6. 必要时同步三层代码自文档

## 项目上下文

### GitNexus 可用时

提供与任务相关的文件 360° 上下文、调用关系和影响面。

### GitNexus 不可用时

提供：
- 相关 `CONTEXT.md`
- 相关文件头部说明
- 必要的相邻上下文

## 完成输出格式

```markdown
## implementer 完成报告

- 已完成内容：
- 修改文件：
- 验证命令：
- 验证结果：
- 剩余风险：
```
```
